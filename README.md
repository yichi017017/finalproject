# 🧠 Python 記憶翻牌遊戲（Memory Match Game）－生存挑戰版

> 一個結合「時間生存戰」與「特殊道具」的經典記憶翻牌遊戲。
---

## 📖 專題簡介（Introduction）

本專案是一款使用 **Python 原生 GUI 函式庫 tkinter** 所開發的記憶翻牌益智遊戲。

有別於傳統靜態的翻牌玩法，本遊戲加入了 **「生存挑戰（Time Attack）」** 機制。  
玩家不僅需要良好的記憶力，還必須與時間賽跑：

- **配對成功** 可以獲得時間獎勵  
- **配對失敗** 會遭到時間懲罰  
- **時間歸零** 則遊戲立即結束  

此外，遊戲中加入了具有戰略性的特殊道具 **「透視眼」**，讓玩法更有深度與變化。

本專案主要練習與應用以下概念：

- Python 物件導向程式設計（OOP）
- GUI 事件驅動（Event-driven）程式設計
- 遊戲狀態管理（State Management）
- 計時器與時間控制邏輯

---

## 🛠️ 使用套件（Requirements）

本專案遵守 **Zero-Dependency** 原則，完全使用 Python 標準函式庫開發，  
**不需要安裝任何第三方套件**（如 Pygame）。

只要電腦已安裝 **Python 3.x** 即可執行。

使用的標準函式庫如下：

- `tkinter`：建立遊戲視窗、按鈕與互動介面
- `random`：隨機洗牌與卡片配置

---

## 🎮 遊戲玩法（Gameplay）

### 🎯 遊戲目標
在 **60 秒倒數時間** 內，找出 **4×4 卡片網格** 中所有 **8 對相同圖案**。

---

### 🕹️ 操作方式

- **翻牌**：滑鼠左鍵點擊卡片
- **使用道具**：點擊下方的「透視眼」按鈕
- **重新開始**：點擊「重新開始」重置遊戲

---

### ⚡ 生存挑戰規則（Survival Rules）

時間就是你的生命值：

| 動作 | 時間影響 | 說明 |
|---|---|---|
| 配對成功 | ⏱️ +5 秒 | 成功獲得時間獎勵 |
| 配對失敗 | ⏱️ -2 秒 | 卡片 1 秒後蓋回 |
| 時間歸零 | 💀 Game Over | 遊戲立即結束 |

---

### 🔮 特殊道具說明

#### 👁️ 透視眼（Magic Eye）

- **功能**：短暫翻開所有尚未配對的卡片（約 1.5 秒）
- **限制**：每一局遊戲僅能使用一次
- **使用時機**：建議在時間緊迫、記憶混亂時使用
